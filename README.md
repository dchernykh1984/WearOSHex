# WearOS Hex

**Hex Duel** for **Wear OS** watches, in Kotlin and Jetpack Compose.

A port of [AmazfitHex](https://github.com/dchernykh1984/AmazfitHex), the same
game as a Zepp OS mini app. The rules, the layout proportions and the eleven
translations are carried over unchanged; the implementation is new.

Built and tested against a **OnePlus Watch 2R** (466x466 round, Wear OS 5).
